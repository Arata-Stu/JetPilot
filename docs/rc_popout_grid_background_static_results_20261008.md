# 固定grid背景方式の静止条件での評価結果

2026-10-08。移動条件で固定した方式を静止18記録へ適用した集計では、飛び出しあり12記録すべてでRGB・EVSとも各1候補があり、飛び出しなし6記録では両者とも候補0件だった。初出現前の候補はなく、初出現後の候補時刻はEVSがRGBより平均17.65 ms早かった。**候補位置は未照合のため、車両検知成功率や確定した検知遅延とは扱わない。**

対象は `grid_background_static_trial01`。入力は利用者側で実行された `summary.csv` と `errors.json` の[貼付原文](evidence/rc_popout_20260930/grid_background_static_20261008/source_user_paste.txt)。[再計算用CSV](evidence/rc_popout_20260930/grid_background_static_20261008/summary_user_paste.csv)、[集計JSON](evidence/rc_popout_20260930/grid_background_static_20261008/aggregate.json)、[出典と確認範囲](evidence/rc_popout_20260930/grid_background_static_20261008/provenance.json)を保存した。リモート上の元CSVのバイト列や推論配列を照合した結果ではない。

## 移動条件と合わせた解釈

今回の静止集計は、移動条件で固定した方式が静止条件でも、飛び出しなしでは警報を出さず、飛び出しありでは初出現付近に候補を出したという結果である。静止側の結果を見て再調整したものではない。

[移動条件の映像照合](rc_popout_grid_background_evaluation_visual_review_20261007.md)では、EVSの初出現後候補8件中、車体との対応を支持する6件、背景1件、判断保留1件だった。さらに正例2記録で初出現前にも警報があった。静止の「12/12件に候補」と移動の「車体との対応を支持する6/8件」は確認段階の異なる指標なので、同じ検知成功率の列へ並べない。

発表の流れは、静止条件での従来方式、自車移動による背景活動の問題、局所背景モデルによる対策、固定方式の移動条件での評価、静止条件への再適用とできる。対策後の静止条件でも候補が得られた点を加えられるが、対象との空間的一致の確認が残る。

今回の時刻差は固定された検知規則の候補時刻であり、センサ単体の遅延、人間のブレーキ反応、オンライン処理時間、制動距離を測ったものではない。従来の静止結果とはROI・投影・規則が異なるため、旧結果との時刻差の増減をそのまま改善量としない。同一入力による単純活動量方式との比較には、今回出力された `baseline_summary.csv` を用いる。
