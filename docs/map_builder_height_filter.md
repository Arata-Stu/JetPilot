# Map Builderの高さフィルター

Map Builder右側の「点群の高さフィルター」で「高さ付き点群を表示」を有効にすると、背景画像の代わりに点群を俯瞰表示します。下限・上限スライダーで表示するZ範囲を変更できます。「全高さに戻す」で解除し、チェックを外すと従来の画像に戻ります。HD Mapの編集、ズーム、カメラ投影は従来どおり利用できます。

- 既存の地図では、最初にRasterを再生成してください。元の `vslam_reference_snapshot.json` にlandmarksが必要です。
- 高さはラスタ生成時の変換適用後の地図座標Z（m）です。床面からの距離ではありません。
- 高さの選択は表示だけに適用されます。HD Mapの保存データ、ラスタの原点・縮尺・表示範囲は変更しません。
- 表示範囲外の点は表示しません。必要ならRasterのクロップ設定を変更して再生成してください。
- フィルター範囲は現在の画面内で保持します。地図の切り替えやページ再読み込み後は再設定してください。

Raster生成時、PNGと同じ名前の `.points.json` に、高さフィルター・XY間引き・クロップ前の点群を地図座標へ変換して保存します。標準名は `vslam_landmarks.points.json` です。ブラウザーの負荷を抑えるため、25万点を超える場合は入力順に均等抽出します。元のスナップショットは変更しません。表示用の抽出で疎な構造が見えにくくなる場合があります。

読み込みはチェックを入れた時に行い、その後のスライダー操作はブラウザー内で完結します。元画像と点群の座標メタデータが一致しない場合や、必要な保存TFがない場合は点群表示を中止し、理由を表示します。

確認用テスト：`node tools/app/frontend/tests/point_cloud_ui.test.cjs`。高さ選別、原点・yaw付きの投影、上下限の交差、無効データ、地図切り替えを確認します。
